Relatório de HTML, CSS e Bootstrap

Atividade desenvolvida com base no template FolioOne, da BootstrapMade, adaptado para um portfólio profissional em HTML, CSS e Bootstrap.

Referências consultadas

Template escolhido: FolioOne - Clean Portfolio Bootstrap Template. A página de categorias da BootstrapMade lista o FolioOne como template moderno e responsivo para portfólios. Para a explicação técnica, foi usada a documentação da MDN sobre introdução ao CSS e seletores CSS.

1. Diferença entre HTML e CSS

HTML significa HyperText Markup Language. Ele é responsável pela estrutura e pelo conteúdo de uma página web. Com HTML, definimos títulos, parágrafos, links, imagens, listas, seções, formulários e a organização semântica da informação.

CSS significa Cascading Style Sheets. Ele é responsável pela apresentação visual da página. Com CSS, controlamos cores, fontes, tamanhos, espaçamentos, posicionamento, bordas, efeitos de interação e adaptação da página para telas diferentes.

As duas tecnologias se complementam: o HTML cria os elementos e dá sentido ao conteúdo, enquanto o CSS seleciona esses elementos e define como eles serão exibidos. Em um portfólio, por exemplo, o HTML marca a seção de projetos e o CSS transforma essa seção em cartões organizados, com cores, imagens, espaçamentos e botões estilizados.

2. Exemplos de propriedades CSS

color: define a cor do texto. Afeta diretamente a leitura e o contraste do conteúdo.

font-size: define o tamanho da fonte. Ajuda a criar hierarquia visual entre títulos, subtítulos e parágrafos.

background-color: define a cor de fundo de um elemento. Ajuda a separar áreas da página e destacar blocos importantes.

margin: cria espaço externo ao redor do elemento. Afasta o elemento dos outros componentes da página.

padding: cria espaço interno entre a borda do elemento e o conteúdo. Deixa botões e cartões mais confortáveis visualmente.

.card-projeto {
  color: #ede9fe;
  font-size: 18px;
  background-color: #24143d;
  margin: 24px 0;
  padding: 32px;
}

3. Formas de aplicar CSS

Existem três formas principais: CSS inline, CSS interno e CSS externo.

CSS Inline

Funciona colocando as declarações CSS diretamente no atributo style de uma tag HTML. Afeta apenas aquele elemento específico.

<p style="color: purple; font-size: 18px;">
  Texto com CSS inline.
</p>

Vantagens: é rápido para testes e alterações pontuais.

Desvantagens: mistura conteúdo e estilo, dificulta manutenção e repetição em várias páginas.

CSS Interno

Funciona dentro da tag <style>, geralmente no <head> do documento HTML. Afeta os elementos da própria página.

<head>
  <style>
    h1 {
      color: #a855f7;
    }
  </style>
</head>

Vantagens: centraliza estilos de uma página sem criar arquivo extra.

Desvantagens: não é ideal para sites com várias páginas, pois seria necessário repetir o CSS em cada arquivo.

CSS Externo

Funciona em um arquivo separado com extensão .css, conectado ao HTML pela tag <link>.

<head>
  <link href="assets/css/main.css" rel="stylesheet">
</head>

Vantagens: facilita manutenção, reaproveita estilos em várias páginas e organiza melhor o projeto.

Desvantagens: depende do carregamento correto do arquivo externo e exige atenção ao caminho do arquivo.

4. Template web e seletores

O template escolhido foi o FolioOne, disponível na categoria de portfólios da BootstrapMade.

Tipo de CSS aplicado no template

O FolioOne usa principalmente CSS externo. No arquivo index.html, o Bootstrap, os ícones, bibliotecas visuais e o arquivo principal do template são importados com <link>. Exemplo:

<link href="assets/vendor/bootstrap/css/bootstrap.min.css" rel="stylesheet">
<link href="assets/vendor/bootstrap-icons/bootstrap-icons.css" rel="stylesheet">
<link href="assets/css/main.css" rel="stylesheet">

Também há uso de atributos HTML como data-aos e classes Bootstrap, mas a estilização visual do template fica nos arquivos CSS externos. Não foi necessário usar CSS inline na adaptação principal.

Seletores simples

Selecionam elementos por nome, id, classe, grupo ou universal.

body { ... }                  /* elemento */
#preloader { ... }            /* id */
.header { ... }               /* classe */
h1, h2, h3, h4, h5, h6 { ... }/* grupo */
.portfolio-home * { ... }     /* universal */

Pseudo-classes

Selecionam elementos em um estado específico, como passar o mouse, foco ou último item.

a:hover { ... }
.navmenu>ul>li:last-child { ... }
.contact .contact-form .form-control:focus { ... }

Combinadores

Selecionam elementos com base em relação entre eles, como descendência, filho direto ou irmão adjacente.

.header .logo h1 { ... }      /* descendente */
.navmenu>ul>li { ... }       /* filho direto */
.page-title nav ol li+li { ... } /* irmão adjacente */

Pseudo-elementos

Selecionam e estilizam uma parte de um elemento ou criam conteúdo visual auxiliar.

.hero .hero-content h1 .highlight::after { ... }
#preloader:before,
#preloader:after { ... }
.page-title nav ol li+li::before { ... }

Seletores de atributos

Selecionam elementos por atributo ou valor de atributo. O template usa atributos para animação, e a adaptação adiciona um seletor para links de email.

[data-aos-delay] { ... }
.portfolio-home a[href^="mailto:"] { ... }

5. Adaptação do portfólio

A página principal index.html foi adaptada para um portfólio profissional completo.

Conteúdo implementado

Foram criadas as seções Sobre mim, Habilidades, Projetos e Contato. A seção de projetos contém dois exemplos reais: Magnolui, uma biblioteca de componentes React, e Text Editor, um editor de texto em JavaScript puro. A seção de contato inclui email, site pessoal, LinkedIn, GitHub e botão de envio de email.

Personalização visual com CSS

As principais alterações foram feitas no final de assets/css/main.css, na seção Portfolio Customization. Foram alteradas as cores principais com variáveis CSS, a tipografia foi trocada para Inter e Poppins, os botões foram personalizados com bordas menores, novo peso de fonte e efeitos de hover, e os links de email receberam destaque por seletor de atributo.

.portfolio-home {
  --default-font: "Inter", system-ui, sans-serif;
  --heading-font: "Poppins", sans-serif;
  --background-color: #160f24;
  --accent-color: #a855f7;
}

.portfolio-home .hero .hero-actions .btn.btn-primary {
  background: var(--accent-color);
  border: 2px solid var(--accent-color);
}
